01 — OVERVIEW

Project Context & Objectives

What It Is

An all-in-one student workspace combining deadline tracking, study progress analytics, and course task management.

Problem Addressed

Students juggle assignments across multiple learning management systems and chat channels, leading to missed deadlines and disjointed study schedules.

What I Built

Constructed a high-performance Next.js productivity platform backed by Prisma, featuring quick task capture, dynamic deadline urgency filters, and visual progress tracking.

02 — KEY FEATURES

Core Capabilities

Task & Deadline Manager

Prioritized assignment timeline highlighting imminent due dates with urgency tags.

Study Goal Tracker

Subject-wise target hour monitor with daily completion metrics and streak counters.

Academic Progress Analytics

Visual grade distribution charts and semester GPA trajectory projections.

Coursework Organization

Organized repository for course syllabus links, project milestones, and exam dates.

03 — TECH STACK

Technologies & Architecture Role

Next.js Full-Stack React Framework & Server Components
Tailwind CSS Utility-First Responsive Theming
Prisma Type-Safe ORM & Relational Schema Modeling
04 — HOW IT WORKS

System Workflow & Architecture

Students enter their courses, deadlines, and study targets. The dashboard automatically calculates upcoming priority queues and updates academic progress charts as tasks are checked off.

01

Course Setup

Define subjects, credit weightings, and assessment schedules.

02

Dynamic Prioritization

Tasks automatically sort by urgency and weighted impact on overall grade.

03

Progress Tracking

Study sessions and completed milestones update visual progress dials.

04

Semester Analytics

06 — CHALLENGES & LEARNINGS

Engineering Takeaways

What Was Difficult

Structuring a database schema flexible enough to handle varied course structures (labs, tutorials, projects) while keeping queries fast.

Technical Decisions

Utilized Prisma relational models to connect courses, assignments, and study logs cleanly with strict type safety.

What I Learned

Mastered Next.js server components, relational data modeling with Prisma, and designing information-dense dashboards that remain clear and uncluttered.

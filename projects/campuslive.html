01 — OVERVIEW

Project Context & Objectives

What It Is

A real-time geospatial discovery platform where students can see what clubs, workshops, or study groups are meeting right now across university grounds.

Problem Addressed

Campus announcements were scattered across multiple unofficial social channels, causing students to miss relevant workshops, tech talks, and cultural events.

What I Built

Created an interactive web map with Firebase Realtime Database integration allowing student organizers to drop activity pins and attendees to discover them instantaneously.

02 — KEY FEATURES

Core Capabilities

Live Campus Map

Interactive map visualization pinning real-time workshops, club meetups, and hackathons across campus venues.

Activity Pins

Color-coded geospatial map markers reflecting activity categories, crowd interest, and ongoing timelines.

Activity Discovery

Filterable feed allowing students to discover happenings by category, academic department, or time.

Event Information

Detailed modal views providing venue directions, agenda outlines, organizer contacts, and RSVP counters.

03 — TECH STACK

Technologies & Architecture Role

React Dynamic Map UI & Filter System
Firebase Realtime Database & Authentication
JavaScript Interactive Map Geometry & State
04 — HOW IT WORKS

System Workflow & Architecture

Event organizers drop an event pin on the digital campus coordinate grid. Firebase broadcasts changes to all active student clients, populating live activity tags on the map.

01

Pin Placement

Organizer selects campus building/room coordinate and adds event info.

02

Realtime Propagation

Firebase synchronizes pin data with active listener nodes instantly.

03

Exploration

Students filter activities by interest (Hackathons, Talks, Social) on the interactive map.

04

Engagement

Students view venue details, start times, and live attendance indicators.

Data Pipeline & Interaction Flow
Organizer Client ↓ Geotagged Pin Submission Firebase Firestore
Firebase Realtime Listener ↓ Instant Sync & Pin Rendering Student Map UI

06 — CHALLENGES & LEARNINGS

Engineering Takeaways

What Was Difficult

Managing responsive SVG/Canvas map scaling across mobile screens while maintaining accurate pin positions.

Technical Decisions

Normalized coordinates relative to a responsive bounding grid rather than hardcoded pixel values.

What I Learned

Gained hands-on experience developing under hackathon time limits, working with NoSQL data schemas, and implementing responsive map interfaces.
